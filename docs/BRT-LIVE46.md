# BRT 19.20.42 预览版：友方人机补位

**怎么用：** 房主在游戏标题页按 `F9`，选择「友方人机补位 → 开启」。不需要先登录。默认关闭；选择会保存在房主的 Windows 用户设置中，从下一场支持原生补位的本机 PvE 对局生效。关闭时沿用地图原有的人机规则，正在进行的对局不变。原版 `F7` 反馈和 `F8` 直播模式保留。

**实测范围：**

- 隔离游戏客户端在标题页收到 `F9` 后，原生提示成为活动的顶层窗口。先触发「关闭」的原生按钮回调，再打开并触发「开启」，房主设置依次读回 0 和 1。此项不是人工鼠标点击测试。
- 另一场普通 MiniFarm 的服务端记录为友方 4 名人机、敌方 5 名人机，总人数 10：1 名真人加 4 名友方人机对 5 名人机。关闭后的开房复测中真人未进入，不能据此报告关闭后的队伍人数。其他地图及多人中途加入亦未逐项验证。
- 窗口回归覆盖首次默认关闭、设置读回、按住快捷键不重复弹窗、其他弹窗不改设置、进入对局后不处理该快捷键。此版未包含正在调查的靶场改动。

**升级：** 退出游戏、专服与旧工具箱，完整解压新版 ZIP 到新文件夹。打开 `BRT.exe`，确认 Steam 游戏目录，点「安装社区环境」，看到 `live46` 就绪或已安装后启动游戏。

**安装验证：** 对最终 ZIP 做了断网全新安装、重复安装和从 19.20.41 玩家包升级。安装器回读了新 DLL 与旧 DLL 备份的摘要；配装、房间配置和游戏程序保持不变。缺失或损坏的离线依赖、未知 DLL 和不支持的游戏版本均被拒绝。
