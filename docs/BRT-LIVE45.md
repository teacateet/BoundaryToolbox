# BRT 19.20.41：雷达高度、换人后的控制和好友房

适用于 Steam《边境》Build 14530908。完整解压新包，在首页点一次「安装社区环境」，等到提示 `live45` 已就绪或已安装。已有 19.20.40 的玩家也需要这一步。

## 看懂头盔雷达

默认按 **Z** 标中敌人，或由肩挂侦察探针标中敌人后，圆点表示目标在雷达平面上的位置。干员图标在线的上端，表示他在你上方；在线的下端，表示他在你下方。和你接近同一高度时，图标回到圆点附近。零重力下翻滚时，“上”和“下”跟随本人的姿态。已标记的弹药箱使用同一高度规则，保留各自的原版图标。

19.20.40 能取得目标的三维位置，但给原版控件的高度字段为零。live45 给同一控件提供相对本人雷达平面的有符号高度，落点、竖线和图标仍由游戏绘制。用同一套 96 个 HUD 场景对照，19.20.40 通过 90 项，live45 通过 96 项。新增检查包括目标穿过雷达平面、本人翻滚，以及同职业敌人投影重叠但高度不同。[雷达回归记录](../integrations/gameplay/community-radar/tests/result.json)

在普通 MiniFarm，用游戏自己的 Z 键标中一名敌人，再改变他相对本人的位置。实机在同一帧读取到本人的标记、相同的职业纹理、圆点、线和图标控件。表中是控件坐标，不是截图的像素测量。

| 敌人相对高度（地图单位） | 本人雷达的职业图标 | 平面落点和线 |
| ---: | --- | --- |
| +1,099.77 | 比落点高 26.39 个界面单位 | 小圆；线的可见标志开启，两端连接图标和落点 |
| −1,100.45 | 比落点低 26.41 个界面单位 | 小圆；线的可见标志开启，两端方向反转 |
| +10.88 | 距落点 0.26 个界面单位 | 大圆，长线隐藏 |

实测覆盖本人手动标中的敌人。本版没有另外取得肩挂探针、补给点在这三种高度下的逐帧画面；它们共用同一投影代码。玩法实机读数来自带观测接口的构建，玩家 DLL 不含这些接口。

## 死亡换人后能否走动、转头

旧版有时要等游戏先解锁键鼠才关闭选人页；若原版漏掉首次关页请求，也不会再尝试。两种情况都可能留下仍在动的画面和没法用的键鼠。live45 先确认本次部署、角色身份和本人实际接管的第一人称角色。输入持续被锁时关闭经核实的旧选人页，下一帧再看菜单是否已退；原生关页请求丢失时最多重试一次。玩家新打开的菜单继续保有焦点。

在同一组 157 个换人场景中，19.20.40 有 5 项失败，live45 全部通过。覆盖持续锁键鼠、第一次请求未生效、取消离场后旧弹窗返回，以及玩家新开的菜单。[换人回归记录](../integrations/gameplay/community-death-menu/tests-19.20.41.json)

在同一局普通 MiniFarm 自然阵亡两次，分别通过可见的干员卡片部署 PROBE、PEACE。第二轮双点干员卡片，在等待时再按 Esc，从原版离场弹窗点「取消」。两轮都不再显示选角页或光标，三个输入锁均已释放，W 和鼠标左右移动都有实测响应。

| 部署 | 从选中到部署 | W 位移（地图单位） | 本人第一人称镜头左右转动 |
| --- | ---: | ---: | --- |
| PROBE | 5 ms | 121.16 | +13.62° / −13.65° |
| PEACE，取消离场后 | 8 ms | 205.65 | −13.64° / +13.66° |

## 和朋友进同一局

| 操作者 | 在工具箱的「联机 → 房间」怎么做 |
| --- | --- |
| 房主 | 点「创建好友房」（默认合作，可选对战）。房间就绪后点「复制好友邀请」，等显示已复制，发给朋友，再点「进入房间」。 |
| 房客 | 复制整条邀请，点「粘贴并加入」。工具箱自动连接本房网络，等房主在线后进入游戏；不用输入 IP、端口或组网密码。 |
| 同一路由器下的玩家 | 房主也可以发「同一 Wi-Fi 邀请」。房客仍点「粘贴并加入」，走局域网。 |

游戏期间双方保持工具箱打开。好友邀请只供本房使用，不带已有高级组网的密码。已经连着自定义网络时，工具箱保留原连接，可从「高级选项」复制已有组网邀请。取消、超时或换房后，上次连接的通知不会再打开游戏。

本机独立 VNTS 2.0.9 的两客户端测试通过后，又检查了默认服务。旧地址拒绝注册，好友房已换用上游 VNT 2 公共服务。最终源码使用内置域名直接注册，生成邀请并让房客从游戏 UDP 入口发送随机数据；房主收到相同内容，回复也到达房客。默认连接和强制服务器转发分别用时 5.65 秒、7.59 秒。这两次都经过公共服务，但客户端在同一台机器上，尚未实测两地家庭宽带或不同运营商。

离屏界面另行验证五步新手向导直接到好友房，不再要求选下载代理或打开高级组网页。最终启动器标准回归 93 项通过、0 项失败、7 项按默认设置跳过；上面的两次公网 UDP 专项是另外显式运行的测试。

## 社区环境离线安装

旧版首次安装要再连 GitHub 和 Node.js 官网。19.20.41 完整 ZIP 内含三个离线依赖包：社区基础文件、社区服及档案服务、Node.js 运行时。安装器从本地打开文件，逐包核对 SHA-256，再写入选定的游戏目录。玩家不需要选代理，收到别人转发的同一完整包也能安装。上游附带的示例玩家配装已排除；[提取规则](../tools/prepare-offline-deps.ps1)和[固定校验值](../tools/offline-components.sha256)可复核。

用最终 ZIP 解压到新的中文路径，在空缓存、不可连接的 HTTP/HTTPS 代理下，只复制正版 Build 14530908 的主程序模拟全新安装。实际安装了 945 个文件；随包 Node.js 24.22.3 可加载服务端依赖。组件缺失或损坏时安装器指出文件名，游戏目录未被修改。已存在的未知 DLL 和不支持的游戏版本也不会被覆盖。

重复安装没有额外备份；从上游 V0.8.4 和 BRT 19.20.35 至 19.20.40 逐版升级时，旧 DLL 备份与原件的 SHA-256 一致，玩家配装、房间设置与游戏主程序未改变。
