# BRT live39 首命与换人验证

本次修复针对普通难度 CircularX 的本地 PvE 对局。使用 BRT 19.20.34 启动器和 Steam Build 14530908 的游戏程序，档案与专服在本机隔离运行。

## 首命的第一人称武器

PEACE 的首命可以同时出现三种状态。背包中已有 AKM，相机已经回到存活角色，当前武器和待装备武器却一直为空。对同一角色执行游戏原有的装备动作后，枪械和已装配件出现在右手。修复只在本地 PvE 的首命生效。回合已经开始、第一人称相机已回到玩家、角色拥有主枪且双手持续空闲 800 毫秒时，客户端才补发一次装备动作。

实机从选角进场，没有提前切枪，画面可直接看到右手的 AKM。测试画面来自普通地图 CircularX。首命测试另覆盖菜单开启、原生已在切枪、归属错误和进入下一条命等 8 种情况。[首命实现与说明](../integrations/gameplay/community-first-loadout/README.md)

## 死亡选角与键鼠

同一次 Esc 能打开选角页并把离场确认框再次压在顶部。此时选角页的打开标志为真，角色控件却收不到输入。部署确认之后，原生流程还可能停留在等待重生的状态。客户端现在检查弹窗是否就是本次 Esc 对应的离场确认，等选角结果后关闭自己的菜单、归还输入，并在死亡控制器仍等待部署时调用正常的重生请求。
