# BRT live39 首命与换人验证

本次修复针对普通难度 CircularX 的本地 PvE 对局。使用 BRT 19.20.34 启动器和 Steam Build 14530908 的游戏程序，档案与专服在本机隔离运行。

## 首命的第一人称武器

PEACE 的首命可以同时出现三种状态。背包中已有 AKM，相机已经回到存活角色，当前武器和待装备武器却一直为空。对同一角色执行游戏原有的装备动作后，枪械和已装配件出现在右手。修复只在本地 PvE 的首命生效。回合已经开始、第一人称相机已回到玩家、角色拥有主枪且双手持续空闲 800 毫秒时，客户端才补发一次装备动作。

实机从选角进场，没有提前切枪，画面可直接看到右手的 AKM。测试画面来自普通地图 CircularX。首命测试另覆盖菜单开启、原生已在切枪、归属错误和进入下一条命等 8 种情况。[首命实现与说明](../integrations/gameplay/community-first-loadout/README.md)

## 死亡选角与键鼠

同一次 Esc 能打开选角页并把离场确认框再次压在顶部。此时选角页的打开标志为真，角色控件却收不到输入。部署确认之后，原生流程还可能停留在等待重生的状态。客户端现在检查弹窗是否就是本次 Esc 对应的离场确认，等选角结果后关闭自己的菜单、归还输入，并在死亡控制器仍等待部署时调用正常的重生请求。

换人时还有一个独立问题。PEACE 和 PROBE 都在本局允许的名单内，但角色列表已选中 PROBE 时，部署按钮自己的角色 ID 仍可能是空值。现在点击部署才从当前配装管理器读取选择，核对本局名单后同步给本人的可见按钮。专服继续执行原来的身份、配装与出生检查。

**2026-11-24 最终实机结果：** 在 CircularX 普通局，PEACE 阵亡后打开选角页，不用预先悬停，直接执行 PROBE 卡片及部署按钮的点击回调。选角页关闭，第二条命实际出生为 PROBE。专服确认 DMR 和 FOP 的配件读回分别为 8/8 和 6/6。客户端确认本人正在控制侦察角色并持 DMR。向游戏窗口发送 W 后，该角色移动约 180 个地图单位；随后移动鼠标，水平朝向变化约 5.46 度。两次采样中角色仍存活，选角页均为关闭状态。

这次检查使用隔离的本机专服、配装副本和带观测能力的零售客户端。Esc 走游戏的输入接口，选择与部署走可见控件的点击回调；没有逐个用物理鼠标点击菜单。复活后用 Windows 键盘和鼠标事件实测。本地档案下，六个可用角色卡片都带有旧的外观锁标记，包括已在使用的 PEACE。点击时按可见性、控件是否启用和本局下发的角色名单进行匹配，保留专服检查。
