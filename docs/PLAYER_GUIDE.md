# BRT 玩家指南

**Windows x64 · BRT 19.20.43 · live47。** 此包适用于 Steam《边境》Build 14530908，包含本地人机的玩法修复。[下载 Windows x64 玩家包](https://github.com/teacateet/BoundaryToolbox/releases/download/v19.20.43/BRT-19.20.43-preview-win64.zip)，无需手动复制 DLL。

登录拥有《边境》的 Steam 账号并装好游戏。完整解压本包到新文件夹，退出旧工具箱、游戏和专服，再打开新文件夹里的 `BRT.exe`。**新玩家和旧版玩家都要在首页点一次「安装社区环境」**。基础组件和 Node.js 已随 ZIP 提供，安装不需要连 GitHub。已装过的玩家选回原来的 Steam 游戏目录；更新保留原配装并备份旧的已识别玩法组件。

本机人机正在开房时，在同一大厅再点同一难度和地区，会继续等待原来的房间。取消后可以重新选择。

从未改过的枪会按原作配件显示。比如 DMR 默认使用 3 倍镜，自己装过 4 倍镜的仍显示 4 倍镜。老档案中明确选择的主副武器、每把枪的配件和手动卸空的装备槽都按玩家的选择读取。

没有选过枪时，大厅会按各干员的原作主副武器显示。例如奥兰的默认副手是 APS，医生的默认搭配是 PCC 和 FOP。

从未选过挂载的奥兰默认左侧电磁、右侧空置，机动模块为钩索。探针玩家自己选过的左蜂巢、右探针以及手动更换的机动模块继续按档案读取。

## 第一次打开

1. 在工具箱首页确认游戏目录。需要手动选择时，在 Steam 库右键《边境》，点「管理 → 浏览本地文件」，再在工具箱里选这个目录。
2. 点「安装社区环境」，等提示 live47 已安装或已就绪，再进大厅。从旧版升级也要执行这一步。
3. 保留程序旁的 `orbital_profile` 文件夹，里面有你的设置和日志。

## 一个人玩人机

1. 在首页打开「本机人机匹配」，点「进入原版大厅」。
2. 在游戏里进「人机对战」。第一张「随机地图 · 随机人机难度」会替你选下一局；想打指定的一局，点带地图和难度的卡，例如「OSS · 普通人机」。第一次提示选择地区时，选「东亚（香港）」并确认。
3. 点一次匹配，保持工具箱开着。首次开房需要等待地图加载。进入地图、角色出生后即可开始。

**友方人机补位：** 房主在游戏标题页按 `F9`，选择「开启」或「关闭」，不必先登录。默认关闭，选择会保存；下一场支持补位的本机 PvE 才会应用，正在进行的对局不变。关闭时保留原模式规则。

只选难度时，地图在该难度支持的范围里随机：简单支持 Warehouse、DataCenter，普通支持 MiniFarm、CircularX、OSS，困难支持 OSS、CircularX。OSS 和 CircularX 也可以只选地图，让游戏随机选难度。选择只对下一局生效，取消后可以重选。这些卡用于本机单人人机匹配。

本机人机中，默认按 `Z` 直接标中敌人，雷达会显示他的职业图标。图标在圆点上方表示目标比你高，在下方表示比你低；两者高度接近时不拉长线。侦察探针扫到的敌人在原版标记有效期间也会显示，转身或视线被挡不会提前撤点。标墙或地面不会生成敌方图标；运动感应器提示附近有敌人，不显示具体位置。

首页显示本次房间的准备和接票进度。交接后，专服报告比赛开始时会显示「本场房间已开赛」，玩家回到大厅时会更新为「已返回大厅」。角色出生情况以游戏画面为准。

友方人机给敌人报点时，目标在自己雷达量程内会出现雷达点。目标在量程外时，看到头顶标记而雷达没有点属于正常情况。部分人机原本就带有 EMP 肩挂；它们瞄准可见敌人时可以自行使用。

## 和朋友一起玩

工具箱「联机 → 房间」分别显示对局里的真人数和好友组网设备数。AI 不计入真人数；朋友已连上组网但还没进游戏，只算设备。没有当前对局数据时显示未知，空房才显示 0。房客可以看到自己已经进入的对局人数。

好友邀请只共享这一间房的游戏 UDP 端口，停止房间后同步撤销共享。通用虚拟网卡未开放。中继证书验证失败时不能建房或加入；同一局域网的朋友可以使用「同一 Wi-Fi 邀请」。公开房间的步骤及中继要求见[工具箱公开房间](BRT-ROOM-DIRECTORY.md)。

| 谁来操作 | 在「联机」里怎么做 |
| --- | --- |
| 房主 | 点「创建好友房」，默认合作，也可以先选对战。等房间开启，点「复制好友邀请」，等到显示邀请已复制后发给朋友，再点「进入房间」。 |
| 收到邀请的朋友 | 在聊天软件里复制整条邀请，到工具箱点「粘贴并加入」。工具箱会连接本房网络，等房主在线后自动打开游戏。无需找 IP、填房号或挑节点。 |
| 同一 Wi-Fi 或同一路由器 | 房主也可点「同一 Wi-Fi 邀请」，朋友还是点「粘贴并加入」。这条路径走局域网。 |
| 房间结束或连不上 | 双方玩的时候都留着工具箱。房主可以「停止房间」。异地连接失败可重试；若已手动加入高级组网，可用「高级选项」中的已有组网邀请。 |

进入对局后，按 **Tab** 查看比分板。本人昵称来自已登录的 Steam 账号；队友的公开昵称还没取到时，游戏会先保留原有名字。开启游戏的**主播模式**时保持匿名。短 ID 是单独一栏，不会改成昵称。

## 遇到问题

- **一直搜索，随后提示「连接超时」**。记下点击匹配的时间和难度，以及有没有出现加载画面。附上同一时间的 `orbital_profile/pve-join.log` 记录。若该文件尚未生成，提供工具箱版本和游戏截图即可。
- **朋友连不上房间**。先请房主确认房间和工具箱仍开着，重新复制一条邀请。不同网络要用「复制好友邀请」；「同一 Wi-Fi 邀请」只适用于同一局域网。工具箱报告连接失败时可以重试。
- **先提示连接错误，随后成功进房**。这条提示的原因仍在排查。反馈时请附上弹窗时间，以及随后是否成功出生。
- **出生配置或换人操作不对**。先确认已经用此版本点过「安装社区环境」。若仍能复现，请记下难度、地图、干员和操作顺序，说明是首命还是复活后。
- **找不到游戏或组件**。回到首页重新选择 Steam 游戏目录，退出游戏后再安装社区环境。
- **首次安装提示离线组件缺失或校验失败**。把完整玩家 ZIP 重新解压到新文件夹，确认 `BRT.exe` 旁有 `components/offline`，再点「安装社区环境」。如果提示的是「获取 Release.zip 失败」，请检查打开的是否仍是旧版工具箱。

**问题反馈 QQ 群 `1048069240`**。在工具箱「设置 → 问题反馈」可以复制群号。反馈时带上版本号、操作时间和截图，遮住账号、外网地址和房间密码。
