# BRT 玩家指南

**Windows x64 · BRT 19.20.39 · live43。** 此包适用于 Steam《边境》Build 14530908，包含本地人机的玩法修复。[下载 Windows x64 玩家包](https://github.com/teacateet/BoundaryToolbox/releases/download/v19.20.39/BRT-19.20.39-preview-win64.zip)，无需手动复制 DLL。

登录拥有《边境》的 Steam 账号并装好游戏。完整解压本包到新文件夹，退出旧工具箱、游戏和专服，再打开新文件夹里的 `BRT.exe`。**新玩家和旧版玩家都要在首页点一次「安装社区环境」**。首次安装需要联网下载基础组件。已装过的玩家选回原来的 Steam 游戏目录；更新保留原配装并备份旧的已识别玩法组件。

本机人机正在开房时，在同一大厅再点同一难度和地区，会继续等待原来的房间。取消后可以重新选择。

从未改过的枪会按原作配件显示。比如 DMR 默认使用 3 倍镜，自己装过 4 倍镜的仍显示 4 倍镜。老档案中明确选择的主副武器、每把枪的配件和手动卸空的装备槽都按玩家的选择读取。

没有选过枪时，大厅会按各干员的原作主副武器显示。例如奥兰的默认副手是 APS，医生的默认搭配是 PCC 和 FOP。

从未选过挂载的奥兰默认左侧电磁、右侧空置，机动模块为钩索。探针玩家自己选过的左蜂巢、右探针以及手动更换的机动模块继续按档案读取。

## 第一次打开

1. 在工具箱首页确认游戏目录。需要手动选择时，在 Steam 库右键《边境》，点「管理 → 浏览本地文件」，再在工具箱里选这个目录。
2. 点「安装社区环境」，等提示 live43 已安装或已就绪，再进大厅。从旧版升级也要执行这一步。
3. 保留程序旁的 `orbital_profile` 文件夹，里面有你的设置和日志。

## 一个人玩人机

1. 在首页打开「本机人机匹配」，点「进入原版大厅」。
2. 在游戏里进「人机对战」，选简单、普通或困难。第一次提示选择地区时，选「东亚（香港）」并确认。
3. 点一次匹配，保持工具箱开着。首次开房需要等待地图加载。进入地图、角色出生后即可开始。

同一难度再次开局会轮到下一张地图。简单包含 Warehouse、DataCenter，普通包含 MiniFarm、CircularX、OSS，困难包含 OSS、CircularX。

首页显示本次房间的准备和接票进度。交接后，专服报告比赛开始时会显示「本场房间已开赛」，玩家回到大厅时会更新为「已返回大厅」。角色出生情况以游戏画面为准。

## 和朋友一起玩

| 谁来操作 | 在「联机」里怎么做 |
| --- | --- |
| 房主 | 在「联机 → 房间」选 PvE 合作或 PvP 对战，点「开启房间」。就绪后点 **「进入自己的房间」**；如果和朋友连着同一 Wi-Fi 或有线网络，把 **「复制局域网邀请」** 得到的邀请发给对方。 |
| 同一局域网的朋友 | 复制房主发来的完整邀请，在「联机 → 房间」点 **「粘贴并加入」**。也可把邀请或旧式地址（例如 `192.168.1.20:7777`）粘到输入框，按回车加入。 |
| 异地的朋友 | 以管理员身份打开工具箱，在「联机 → 网络」连接同一 VNT 组网。双方使用同一组网服务器、房间号，以及房主设置的密码（如有）；邀请不含这些凭证。已有连接可直接用。房主开启游戏房后点 **「复制组网邀请」**，朋友复制后在「房间」点 **「粘贴并加入」**。若接到邀请时还没连接，工具箱会保留邀请；连接后点 **「加入邀请房间」**，不用重新填写端口或查找节点。无网卡模式的房主选「我是房主」。 |
| 想中止或重来 | 建房过程中点「取消建房」，等清理结束可以再开。失败弹窗点「确定」，再选「返回」或「重新建房」；若 UDP 端口已被占用，换个空闲端口。组网连接或重试时点「取消连接」，改房间号或服务器后可以重新连。 |
| 游戏结束后 | 房主点「停止房间」。再次开启 PvE 合作房会轮到下一组难度和地图。 |

进入对局后，按 **Tab** 查看比分板。本人昵称来自已登录的 Steam 账号；队友的公开昵称还没取到时，游戏会先保留原有名字。开启游戏的**主播模式**时保持匿名。短 ID 是单独一栏，不会改成昵称。

## 遇到问题

- **一直搜索，随后提示「连接超时」**。记下点击匹配的时间和难度，以及有没有出现加载画面。附上同一时间的 `orbital_profile/pve-join.log` 记录。若该文件尚未生成，提供工具箱版本和游戏截图即可。
- **朋友连不上房间**。请房主确认游戏房仍开着并重新复制邀请。局域网邀请只能在同一局域网使用；异地要使用组网邀请，并确认双方处于同一组网、能在节点列表看到对方。
- **先提示连接错误，随后成功进房**。这条提示的原因仍在排查。反馈时请附上弹窗时间，以及随后是否成功出生。
- **出生配置或换人操作不对**。先确认已经用此版本点过「安装社区环境」。若仍能复现，请记下难度、地图、干员和操作顺序，说明是首命还是复活后。
- **找不到游戏或组件**。回到首页重新选择 Steam 游戏目录，退出游戏后再安装社区环境。
- **首次安装提示下载失败**。确认能访问 GitHub 和 Node.js 官网，再点「安装社区环境」。已经下载并通过校验的组件会继续使用，不需要重新解压。
