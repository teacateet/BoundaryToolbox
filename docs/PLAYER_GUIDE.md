# BRT 玩家指南

**本轮测试包状态（2026-11-23）：19.20.32 已撤回，无需重测。** 维护版已经在 Steam 大厅读回保存的配装，包括 DMR 与 FOP 的配件、枪身涂装，以及宇宙麻雀和探针。尚未验证对局出生后两把枪实际使用这些配置；挂载收起、死亡选角、雷达与钩索第二次出绳也还没有新版实机验收。以下是旧版的使用说明。

当前面向玩家的版本为 Windows x64 19.20.31。先登录拥有《边境》的 Steam 账号，装好游戏，再把 BRT 压缩包完整解压到新目录，打开 `BRT.exe`。升级时选回原来的 Steam 游戏安装目录，工具箱会使用该安装里的玩家配装。

19.20.31 已知问题会影响对局出生配装和挂载。军械库里装好的瞄具可能在出生后还原，宇宙麻雀的准星可能盖在枪械前，钩索在同一条命中可能无法再次使用。

本机人机正在开房时，在同一大厅再点同一难度和地区，会继续等待原来的房间。取消后可以重新选择。

从未改过的枪会按原作配件显示。比如 DMR 默认使用 3 倍镜，自己装过 4 倍镜的仍显示 4 倍镜。老档案中明确选择的主副武器、每把枪的配件和手动卸空的装备槽都按玩家的选择读取。

没有选过枪时，大厅会按各干员的原作主副武器显示。例如奥兰的默认副手是 APS，医生的默认搭配是 PCC 和 FOP。

从未选过挂载的奥兰默认左侧电磁、右侧空置，机动模块为钩索。探针玩家自己选过的左蜂巢、右探针以及手动更换的机动模块继续按档案读取。

## 第一次打开

1. 在工具箱首页确认游戏目录。需要手动选择时，在 Steam 库右键《边境》，点「管理 → 浏览本地文件」，再在工具箱里选这个目录。
2. 第一次使用社区环境，点「安装社区环境」，等安装完成。已经能用社区组件进入大厅的玩家可以直接开始。
3. 保留程序旁的 `orbital_profile` 文件夹，里面有你的设置和日志。

## 一个人玩人机

1. 在首页打开「本机人机匹配」，点「进入原版大厅」。
2. 在游戏里进「人机对战」，选简单、普通或困难。第一次提示选择地区时，选「东亚（香港）」并确认。
3. 点一次匹配，保持工具箱开着。首次开房需要等待地图加载。进入地图、角色出生后即可开始。

同一难度再次开局会轮到下一张地图。简单包含 Warehouse、DataCenter，普通包含 MiniFarm、CircularX、OSS，困难包含 OSS、CircularX。

首页显示本次房间的准备和接票进度。交接后，专服报告比赛开始时会显示「本场房间已开赛」，玩家回到大厅时会更新为「已返回大厅」。角色出生情况以游戏画面为准。

## 和朋友一起玩

| 谁来操作 | 在「联机」里怎么做 |
| --- | --- |
| 房主 | 在「联机 → 房间」选 PvE 合作或 PvP 对战，点「开启房间」。等房间就绪，把自己的局域网地址和游戏端口发给朋友。房主自己加入时使用 `127.0.0.1` 和刚开的端口。 |
| 同一局域网的朋友 | 输入房主发来的地址和端口，例如 `192.168.1.20:7777`，点「加入对局」。 |
| 异地的朋友 | 双方先通过「联机 → 网络」连入同一个 P2P 网络。房客选择房主节点，填写房主的游戏端口并加入。启动 P2P 会话时按 Windows 提示使用管理员权限。 |
| 游戏结束后 | 房主点「停止房间」。再次开启 PvE 合作房会轮到下一组难度和地图。 |

## 遇到问题

- **一直搜索，随后提示「连接超时」**。记下点击匹配的时间和难度，以及有没有出现加载画面。附上同一时间的 `orbital_profile/pve-join.log` 记录。若该文件尚未生成，提供工具箱版本和游戏截图即可。
- **朋友连不上房间**。双方核对游戏端口，房客填写房主的地址。跨网络时检查双方能否在 P2P 节点列表看到对方。
- **先提示连接错误，随后成功进房**。这条提示的原因仍在排查。反馈时请附上弹窗时间，以及随后是否成功出生。
- **出生配件与选角不同**。已有普通局记录显示，奥兰的 TK47 在选角时为 75/300，出生时变为 30/120。反馈时写明干员和主副槽。选角弹量与刚出生时的弹量最便于对照。
- **挂载、钩锁、换人和雷达**。左蜂巢无响应、右探针使用后主动切枪挡脸、钩锁冷却后无法再次使用、死亡时按 Esc 进入退出界面，以及局内雷达空白，均在跟进。反馈其中一项即可，附上当时的难度和地图。
- **找不到游戏或组件**。回到首页重新选择 Steam 游戏目录，退出游戏后再安装社区环境。
