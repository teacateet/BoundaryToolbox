server source used for the supported release, and BRT's transformation scripts
and patches. Decompress profile-runtime/release-084-code.json.gz to read the
UTF-8 JSON mapping of original relative paths to their source text. The
pack-release.cjs script lists the original release inputs. No player saves,
retail game executable or Steam credentials are included.

Offline installer: components/offline includes only selected install files from
the pinned Stable, V0.8.4 and Node.js v24.22.3 Windows x64 archives.

The server's bundled licenses and the Node.js license are kept. Upstream example
player profiles, updater tools and npm are omitted. See tools/prepare-offline-deps.ps1
and tools/offline-components.sha256 in the BRT source. Node's runtime license
installs alongside node.exe. The BRT mark and launch
page are original to this project; any Steam library art is read at runtime.
