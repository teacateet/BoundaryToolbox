# 开场动画后的首次出生

社区服普通 PvE 开场动画结束时会调用 `ForceFirstLifeSpawn` 恢复玩家镜头。原流程会重新创建出生队列记录，把角色直接标成已选角。即使游戏已经交付了可玩的角色，也会再请求一次生成。玩家反馈挂载按不出来发生在每局第一次出生。

现在由游戏已确认的选角决定何时允许首次生成。已有的生成进度会保留。如果游戏已经交付一个存活、属于当前玩家的角色，就把镜头切回这个角色。拥有者尚未确认时，沿用原来的占有确认流程。玩家继续使用同一个角色及其身上的装备。这个处理仅由开场动画启用。后续死亡复活使用各自原来的流程。

两套社区源码均已编译。每套各用旧版和修复版执行 11 个离线场景，共 44 次。旧版会在尚未选角时发出一次生成请求，也会替换已正常出生角色的左右挂载。候选在这两种情况下额外生成均为零。待确认的角色仅完成一次占有确认。Steam 客户端在开场结束后实际按下挂载键的结果仍待局内验证。[组合编译结果](../community-stack/verification.json) · [行为回归](tests/verify.ps1)
