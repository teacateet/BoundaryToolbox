# 首次普通局选角菜单

OSS 普通局（live35，专服 PID 21664）的原生事件依次是 `ClientInitFieldMod`、确认角色、出生。异步预订尚在等档案，就因角色已选而取消；同一场的两次军械库回包均包含六名干员。

本补丁在同一份已核验的连接快照上准备第一次原生菜单回包，不重复发送 RPC。只替换本局允许角色的主副枪、左右挂载、近战、机动；保留服务器的准入列表、配额、未知角色及玩家明确的空槽。嵌套装备数组使用独立构造的存储，不持有或释放引擎输入。仅在把初始菜单交给玩家前最后尝试一次已有的受保护预订；菜单交出、原生订单或确认角色均停止本次自动预订，避免后续 Tick 覆盖玩家选择。

`field-menu-forwarded` 表示选角回包已发送，不能证明角色身上已装备，也不是武器涂装或部件的验收。
