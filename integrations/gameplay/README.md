# Steam 对局玩法源码

此处存放自有 UE 玩法实现。当前 Steam 客户端和专服没有加载它们，不能据此批准玩家发行。原版宿主核查

工具箱已有接得上的部分：从原大厅自动开的单机 PvE 会把本机档案地址交给该房间的专服，为该房间登记读取权限。可编译的接收端使用 `RoomHttp::FromLocalServer()` 取得本房连接。档案服务只在 HTTP 响应发出后记录本条生命；首页分别显示已开赛、等待配装和已发出配装。完整数据已由测试接收端读取，尚未观察到零售角色在自己的每次出生时调用它。空专服与档案两条验证链

完整出生流程需要专服在实际认证、角色选择、每次出生以及拥有的武器实例建立时交付业务对象。角色类目的映射使用同一干员实际的原厂配置；没有可匹配的默认类别会拒绝应用，不会写入别的外观槽。显示和输入组件需要能构建客户端玩法的宿主。旧的展厅刷新只能改变大厅模型。[出生声明检查](../spawn/declaration-check.cpp) · 角色与原作默认资产
