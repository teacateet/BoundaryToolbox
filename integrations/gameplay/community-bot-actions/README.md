# PvE 人机出生装备与肩挂

专服只处理原生 `BotControllers` 当前控制的活角色。出生后 0.3 至 10 秒内，武器和载具就位时尝试一次；必须同时有 AI 玩家状态、AI 干员行和当前武器归属。这不会修改真人档案或全局装备定义。

当前枪只抽已装的枪口和瞄具槽，候选来自该枪对应槽位，再查零售配件定义。原生枪实例和供弹槽保留，处理后弹量不超过之前。肩挂从该干员的原生候选中抽取，最多替换一个已有挂点；保持原挂点弹量上限，未能确认新挂载归属则恢复旧件。当前支持普通 EMP、HE 和冲击弹，不把侦察、维修或锁定型挂载当作直接攻击装备。

角色存活、目标为敌人、行为树接近瞄准、原生视线通过且挂载有弹时才触发原生按下与松开。出生后最早 3 秒使用，冷却 18 秒。

本机困难 OSS 中，专服给 AI_PEACE 的 AKM 装上 `RU-AKM_SGT-NITE`，测试客户端在同一 AI 的复制装备中读到相同瞄具和 HE 肩挂。另一次同地图对局中，AI_PROBE 的 HE、AI_FIXER 的冲击弹和普通 EMP 在自然交战中分别从 1 发变为 0。只把弹量实际减少的记录计为使用成功。没有验证所有干员、地图和配件。
