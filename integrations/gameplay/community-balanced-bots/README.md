# 本机 PvE 的友方人机补位（live46）

房主可在游戏标题页按 `F9`，在「友方人机补位」中选「开启」或「关闭」，无需先登录。快捷键也在本地大厅和军械库世界监听。首次使用默认关闭，选择按 Windows 用户保存。新对局开始时读取设置；已经开打的对局不增减人机。加入别人房间时，由房主的设置决定。

开启后，如果原版 PvE 模式有两支队伍、仅为敌方设置了人机席位，而且支持原生补位，就按该模式的席位数为双方补人。关闭则保留模式原有规则。隔离的普通 MiniFarm 对局记录到 1 名真人和 4 名友方人机，对面 5 名人机。其他地图、多人中途加入及游戏内关闭后重新开房，不能由这条记录推断。

原版大厅的 `F7` 会打开反馈，`F8` 会打开直播模式。组件通过本游戏窗口接收 `F9`，避免依赖菜单是否把按键交给玩家控制器。对局和其他窗口不处理此快捷键。

回归用例 [tests/menu.cpp](tests/menu.cpp) 用真实 Win32 窗口、隔离注册表和游戏菜单替身验证首次关闭、两个按钮、状态读回、按住不重复弹窗、忽略其他弹窗及不在对局中响应。它不验证 Unreal 的菜单层或实际鼠标操作。此功能从 19.20.42 玩家包开始提供。

独立游戏客户端在标题页收到 F9 后，原生提示确实成为活动的顶层弹窗。两次走原生按钮回调，分别读回关闭（0）和开启（1）。此项验证没有使用人工鼠标点击。
